Moving backup to disk folders for Backup Exec 11d

I had a situation that required me to change the IP address of the NAS for the Backup to disk folders. Now the location of the folders cannot be changed in the properties. Symantec recommends to create a new location and copy the files across.

That seems to be too complicated, since I am changing the IP address of my NAS, the location of the files remain the same. I really can't do a source and destination copy.

There got to be a simpler way.

Login to the media server as the Backup Exec Service account. You are using the administrator account as the service account? Naughty, Naugthy go sit in the corner.

Stop all Backup Exec services. Change the IP address of the NAS. Start all Backup Exec services. The Backup to Disk folders will now show as offline.

Delete the Backup to Disk folder and create a new one. This time with the new IP address, but with the same folder structure. Backup Exec will give a warning message "An unknown Backup to Disk folder exists, do you want to create". Click on Yes and it will create the folder. All the old media inside will now be available!
