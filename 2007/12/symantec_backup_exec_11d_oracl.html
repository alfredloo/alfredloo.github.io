Symantec Backup Exec 11d Oracle Agent is broken

I was installing Symantec Backup Exec 11d to back up a bunch of servers with Oracle database. After several fruitless sessions to get the Oracle Agent to work, I logged a call to Symantec Support.

The good folks there tried really hard. Change logon accounts, recreate logon accounts, checked RMAN, run scripts. Escalated to 2nd level, third level, from India I ended up in the UK! The service engineer did another round of data collection and testing to no success.

On another day, I called up to follow up on the progress. This time I ended up in Australia! Never mind about the bouncing around the world because this eagle eyed service engineer decided to checked the RMAN error against Symantec database and found that the Oracle Agent is broken.

Oracle Recovery Manager (RMAN) backups fail intermittently with error: ORA-19506: failed to create sequential file
