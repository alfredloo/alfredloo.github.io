Trend Micro OfficeScan and ServerProtect

After a long lull, I get to work with Trend Micro products again. OfficeScan has really evolved. The current version 8.0 will work with IIS or Apache 2.0 (only). If it detects an IIS web server, it will proceed to install for it. Otherwise it will install Apache 2.0. Note this is located in OfficeScan folder, not Apache Project.

OfficeScan requires you to keep track of the management and client communication port. With these 2 bits of information, transferring clients between servers of different version is a real snap. Older clients on a OfficeScan 8.0 server will get automatically upgraded without prompts. So be careful!

ServerProtect for Windows, 5.58 is a tight product, unlike OfficeScan does not require a web server. It has its own management interface. Moving clients is just a simple matter of doing a right mouse click and select the appropriate option.

Installing ServerProtect on Windows 2003 servers, you may encounter services cannot start. This article and this can help.

Upgrading the program can a breeze or nightmare. It all depend on how you look at it. Download the latest patch and install in the Information server. After 30 seconds it will automatically deploy to all the Normal servers. If you want to test the patch first, you want to install on a Normal server first.
