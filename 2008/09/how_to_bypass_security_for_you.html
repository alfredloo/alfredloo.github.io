How to bypass security for your UIQ3

How to install unsigned applications for your UIQ3 device. I have tried this successfully on my P1i

Briefly, you need to unlock the protected folders to install two applications and a driver. One to unlock security, the other to take unsigned applications.

Follow this http://www.agathosyne.de/files_ext/CapsSwitch.zip to download the software to unlock protected folders. Note this involves installing Python, Extensions for Windows and Serial Port Extensions. If you are not comfortable using the software here, you can download the latest version from SourceForge. I did.

A better guide to use the software is available http://aeblogs.com/uiq/how-to-access-uiq-protected-folders

Don't forget to install CapsSwitch and copy the driver to device's c:\sys\bin folder.

Install installserver.exe from http://www.agathosyne.de/files_ext/sis-installer_mod.zip
Note I tried using swmail's installserver.exe, it does not work. Installing any application just causes the screen to blink.

Once the installserver.exe is in, you can install any software you desire at your own risk.
